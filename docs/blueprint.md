# **App Name**: RailFlow Optimizer

## Core Features:

- User Authentication: Secure user login and authentication using JWT.
- Real-Time Train Scheduling: Accept real-time train data, track availability, and priorities to generate an optimized, conflict-free schedule.
- Disruption Management: Dynamically re-optimize the schedule when disruptions occur, such as weather events or breakdowns.
- What-If Scenario Simulation: Simulate alternative routing/holding/platform strategies to compare outcomes and optimize decisions.  An AI 'tool' helps refine the parameters.
- Dashboard and KPI Visualization: Display key performance indicators, such as punctuality and average delays, in a visually appealing dashboard using charts and graphs.
- Scenario Explanations: Explain the reasoning behind specific scheduling decisions, such as why a train is prioritized or rerouted.
- Audit Trail: Maintain a log of decisions, controller overrides, and performance metrics for auditing purposes.

## Style Guidelines:

- Primary color: A vibrant Indian Saffron (#FF9933) to reflect the heritage and energy of Indian Railways.
- Background color: A desaturated off-white (#FAF9F6), providing a clean and non-distracting backdrop.
- Accent color: A deep teal (#008080) to highlight important elements and CTAs.
- Body font: 'PT Sans', a humanist sans-serif with a modern and slightly warm feel, suitable for body text.
- Headline font: 'Playfair', a modern serif, high contrast, geometric, fashionable feel for headlines.
- Use clear, intuitive icons from a modern set, with line weights matching the overall aesthetic, consistently applied throughout the UI.
- Implement a clean, responsive layout using a grid system for optimal viewing on different devices, ensuring all key information is easily accessible.
